# Historical PR1 programs

These three standalone programs record the original setup and PR1 THR/IQR experiments. They are excluded from Maven's active source tree. The current ConsolidationExperiment already implements THR and IQR, so no current policy has been removed.

For current work use scripts/run.ps1. To reproduce the complete earlier project, inspect Git revision 62b38f3 or an earlier PR1 revision in a separate checkout; do not copy these files into src just for ordinary runs. The original reports and screenshots retain their historical filenames.
